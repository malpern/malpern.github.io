# malpern.github.io

Serves documentation for projects that moved from `malpern` to the [Malpern Labs](https://github.com/malpern-labs) organization, at their original addresses. Shipped apps link to these addresses, so they must not change.

- `https://malpern.github.io/KeyPath/` is built hourly from [malpern-labs/KeyPath](https://github.com/malpern-labs/KeyPath)'s `gh-pages` branch by [`.github/workflows/keypath-docs.yml`](.github/workflows/keypath-docs.yml).

Do not create a repository named `KeyPath` under `malpern`: it would take over that path and break GitHub's redirects to the moved repository.
